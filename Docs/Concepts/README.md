# Concept Frames

Concept frames in this directory are visual-development references. They are not final game assets and are not imported into a shipping scene.

Each frame explores one controlled rendering direction while preserving the same product and layout requirements:

- open-side bakery food truck;
- readable refrigerator, oven, baker, counter, and customer path;
- softly staged three-quarter camera;
- restrained cream, crust, cocoa, sage, cherry, and evening-blue palette;
- room for the bottom recipe rail;
- no borrowed characters, logos, or interface designs.

## Planned variants

1. **Soft Sculpted Afternoon** — rounded miniature geometry, gentle material wear, late-afternoon warmth.
2. **Hand-Painted Market Morning** — flatter painted materials, brighter air, stronger graphic silhouettes.
3. **Tactile Evening Bakery** — the upgraded wooden building, deeper cocoa values, practical lights, and the future neon mood.

The selected direction will be recreated with authored Unity materials, models, lighting, and UI. Any generated lettering, geometry, or product detail is non-binding.

## Current synthesis

The production target combines the second frame's unmistakable miniature scale and compact character proportions with the third frame's lighting hierarchy. The first frame remains the food-material reference. None of the frames is a direct modelling sheet.

The normalized generation briefs are recorded in [Prompts.md](Prompts.md).
