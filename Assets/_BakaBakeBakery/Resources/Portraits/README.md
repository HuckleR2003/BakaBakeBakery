# Character portrait set

These six portrait images were supplied directly by the Baka Bake Bakery project owner on 2026-08-01.

Runtime mapping:

- `main.jpg` — Jules, the player baker
- `mila.jpg` — Mila, friend and tutorial guide
- `grandma.jpg` — Mrs Rose
- `neighbour_elder.jpg` — elder neighbour
- `neighbour_young.jpg` — young neighbour
- `shop_seller.jpg` — morning-market seller

The original images are kept unchanged. Unity loads them as dialogue and map portraits from `Resources/Portraits`; world models echo their hair, clothing and colour cues instead of placing a flat photograph over a 3D face.
